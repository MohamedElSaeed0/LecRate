# LecRate - نظام تقييم المحاضرين

نظام ويب متكامل وحديث يتيح للطلاب تقييم المحاضرين والمقررات الدراسية بسرعة وسرية وأمان، مع لوحة إدارة تفاعلية لعرض مؤشرات الأداء والتقارير البيانية.

يعتمد LecRate على تقييمات نصية سرية؛ حيث يكتب الطالب رأيه بدون حفظ هويته في جدول التقييمات، بينما تراجع الإدارة الإجابات وتصدر تقييم اعتماد (`AdminRating`) لكل محاضر.

## المميزات الرئيسية

- **سرية تامة**: كل تقييم يخزن بـ `AnonymousHash` بدون حفظ هوية الطالب في جدول التقييمات
- **تقييم نصي**: آراء مفصلة بدل النجوم فقط
- **تقييم إداري**: الإدارة تقرأ التعليقات وتضع درجة اعتماد /100
- **فتح وقفل التقييم**: التحكم في فترة التقييم من لوحة الإدارة
- **Rate Limiting**: حماية من إغراق الخادم بالطلبات
- **واجهة عربية حديثة**: RTL + Chart.js + responsive

## التقنيات

- **Backend**: ASP.NET Core 8 Web API (C#)
- **Frontend**: HTML, CSS, JavaScript, Chart.js
- **Database**: SQL Server + EF Core

## التشغيل

1. انسخ `appsettings.Development.json.example` إلى `appsettings.Development.json` وعدل connection string والأسرار.
2. طبق migrations:
   ```bash
   dotnet ef database update
   ```
3. شغل المشروع:
   ```bash
   dotnet run
   ```
4. افتح المتصفح على رابط المشروع المحلي.
5. سجل دخول كـ Admin ثم استدع `GET /api/seed` لإدخال بيانات تجريبية.

## آلية السرية

```text
SHA256(studentId | lecturerId | subjectId | questionId | SecretKey)
```

- `studentId` يؤخذ من JWT في السيرفر، وليس من الفرونت
- نفس الطالب لا يستطيع تقييم نفس السؤال لنفس المحاضر مرتين
- الإجابات النصية لا تظهر للطلاب الآخرين، وتتاح للإدارة والمحاضر المعني فقط
