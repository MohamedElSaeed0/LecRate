# LecRate - نظام تقييم المحاضرين

نظام ويب متكامل وحديث يتيح للطلاب تقييم المحاضرين والمقررات الدراسية بكل سرعة وسرية وأمان، مع لوحة إدارة ذكية وتفاعلية لعرض مؤشرات الأداء والتقارير البيانية للجامعة.

## 🚀 المميزات الرئيسية
- **سرية تامة**: حماية هوية الطلاب باستخدام نظام تشفير فريد لكل تقييم.
- **لوحة تحكم إحصائية**: عرض إحصائيات وتقارير بيانية تفاعلية للمحاضرين والإدارة العليا (Charts).
- **أداء مستقر**: حماية ضد إغراق الخادم بالطلبات باستخدام Rate Limiting.
- **تصميم عصري وجذاب**: واجهة مستخدم متناسقة ومريحة للعين تدعم مختلف الشاشات والهواتف.

## 🛠️ لغات وتقنيات التطوير
- **Backend**: ASP.NET Core Web API (C#)
- **Frontend**: HTML5, Vanilla CSS, Vanilla JavaScript, Chart.js
- **Database**: Microsoft SQL Server (EF Core)
